# Caremon

پلتفرم اجاره خودرو و رزرو آنلاین ماشین در ایران

[Demo](https://caremon-nextjs.vercel.app)

## فناوری‌ها

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Zustand** (state management)
- **Prisma** (ORM)
- **shadcn/ui**

## شروع سریع

```bash
npm install
npm run dev
```
